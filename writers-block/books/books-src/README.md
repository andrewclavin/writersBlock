## `books-src/`

Place raw book source text files here.

- **Public domain** books: add the `.txt` files to git.
- **Local-only / copyrighted** books (example: `old-man-and-the-sea.txt`): keep the file only on your machine. This repo ignores that filename so it can never be committed accidentally.

Recommended filenames:

- `great-gatsby.txt`
- `age-of-innocence.txt`
- `his-family.txt`
- `old-man-and-the-sea.txt` (local-only; ignored)
